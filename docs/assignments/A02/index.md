## Decide
Since the force at C and the force at D were going in opposite directions, I wanted to design an asymmetrical truss in order to better distribute the internal forces. In addition, I noticed that one of the parameters of the assignment was assuming that "elements that are in compression won't fail in buckling". As such, I made element CE longer and element DE shorter to take advantage of that.

The CAD software I used for this assignment was Solidworks. Solidworks does not have A500 Structural Steel, so I chose Alloy Steel. The pins are made up of hardened tool steel; the specific material I chose in Solidworks was "AISI Type A2 Tool Steel", as it was the only tool steel option the program had.
