# A4 – Motor Mount

## First Steps
I started by deciding that the material I would use is ABS. I created a solidworks file and saved it with the proper name. I started writing down the given parameters, and noticed that the units of this assignment were in Newtons and millimeters, so I changed the unit system in my solidworks file accordingly.

I created an L-shaped bracket in Solidworks, defining my variables so that later when I determined the actual values of each variable, the assigning of dimensions would already be done.

I also added a circular cut in Feature 1 for the motor shaft.
